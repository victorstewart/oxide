# Apple benchmark contract and telemetry ring

## Telemetry availability

Every timed comparison session now persists `telemetry.coverage.json` and binds its path and SHA-256 in the complete envelope. The artifact lists every declared binary event kind, its observed count, and one explicit availability class: required common-ring boundary, conditional common-ring boundary, Oxide-only diagnostic, pass-disabled diagnostic, external evidence, or unavailable. Validation rejects any sample recorded under an external, disabled, or unavailable kind, so an absent framework-internal stage cannot silently become a zero-duration result.

`readyToInput` is the durable-ready boundary observed symmetrically by the executor. `presentation` remains external Animation Hitches frame-lifetime correlation; a display-link callback is only `displayOpportunity` and is never relabeled as presentation. AppKit layout/render/encode/GPU boundaries remain unavailable where the framework does not expose a clock-aligned boundary. In diagnostic passes, the benchmark-only Oxide runtime records clock-aligned render-prepare, encode, command-submit, and drawable-wait boundaries without changing production Oxide. Oxide command-buffer GPU completion remains a duration-only diagnostic (`gpuDuration`) because the comparison ABI exposes completed duration but not a clock-aligned GPU start/end timestamp. The older `gpuEnd` label is therefore never emitted.

`Shared/Foundation/BenchmarkContract.swift` is the Swift binding for the framework-neutral scenario contract. It decodes snake-case v1 manifests, rejects the wrong viewport or clock discipline, resolves artifacts only beneath one canonical resource root, recursively verifies every referenced SHA-256 including the scenario manifest itself, asset-manifest members, and font licenses, and loads integer trace events. Asset loading also decodes `BenchmarkInlineTextAtlas` and requires the same positive grid, verified raster variants, unique roles/em sizes, exact grid-derived dimensions, unique graphemes/cells, and integer-millionths text metrics as Rust. Font-pack loading requires unique roles, nonempty unique four-byte OpenType variation tags, supported axis ranges, and committed file-backed CoreText descriptors. `BenchmarkAppleFontCatalog` registers those exact files and creates each requested size with every manifest axis in `kCTFontVariationAttribute`; it verifies the resulting file URL and effective variation values and never asks CoreText for a system substitute. Packed campaigns use the exact scenario identity from the root plan; relative-path-only scenario loading remains limited to preview and hostless development paths. Apple adapters share the same `prepare`, `reset`, `apply`, `checkpoint`, and `teardown` protocol.

`benchmarkCheckpoint` wraps an adapter-owned live model with observed role counts and constructs the cross-framework semantic accessibility tree. It does not synthesize phase time or scene state from the expected checkpoint. Every node carries role, name, value, state, order, focus, actions, logical frame, count, and visibility before exact comparison with the frozen schema-version-2 artifact. On macOS, `BenchmarkMacOSCorrectnessGeometryCapture` separately records the adapter's live root and nonempty runtime geometry nodes under the frozen `macos-canonical-srgb8-3x-v1` profile. The helper rejects translated, non-finite, nonpositive, fractional-root, off-grid, or noncontiguous evidence before persistence and declares exact point tolerances. AppKit view/text nodes and Oxide encoded primitive/glyph nodes are source-specific; semantic role/ID rectangle pairing remains a required follow-on.

`Shared/Foundation/BenchmarkTelemetryRing.swift` owns the common measured-window event ABI. Its storage is allocated to a fixed capacity before measurement. Appends write only fixed-width integer records with a contiguous sequence; they perform no file I/O, JSON serialization, string formatting, or growth. Overflow is sticky and makes the session invalid. Stable string identities are hashed before entering a measured phase.

The current event vocabulary covers scenario, phase, checkpoint, input, mutation, layout, native/Oxide scene update, render preparation, encoding, submission, GPU timing, presentation, readiness, display opportunities, and reset completion. Implementation-only diagnostics remain separate from this common ring.

The harness unit tests prove exact capacity behavior, contiguous sequences, sticky overflow failure, stable timestamp capture, artifact SHA enforcement, traversal rejection, inline-text atlas decoding, and every role's effective CoreText variation values. CoreText omits an axis from `CTFontCopyVariation` when its selected value equals the font's declared default, so the assertion resolves omitted entries through `CTFontCopyVariationAxes` before comparing the manifest's millionth-scaled value. UI adapters and durable post-phase flushing consume this boundary; the Phase-0 probe is not upgraded into benchmark evidence merely by the presence of the ABI.
