# macOS trusted-input control

`MacOSTrustedInputControl.swift` is a comparison-only boundary between timed benchmark schedules and public XCUI input. It mirrors the Rust preflight by compiling click, wheel, composer text, the frozen adjacent `chat:append:16` select/replace pair, adjacent key-pair, single-pointer drag, exact image-pinch substitution, and exact navigation-cancellation substitution commands; constituent events are marked absorbed and resize, orientation, theme, scale, non-user mutation, resource-arrival, and pressure remain explicitly labeled application stimuli. Other multipointer/pinch or cancellation traces, IME, arbitrary selection ranges, and unreceipted lifecycle transitions fail closed.

Each admitted user command creates a generation- and session-sequence-bound durable request. A background queue performs a controller-ready/request/receipt Darwin handshake, then validates an exact durable foreground receipt whose SHA-256 and dispatch path match the request. No notification wait or receipt read runs on the application main thread.

`MacOSTrustedInputXCUIController` runs in the separately built UI-test runner. Before the controlled start barrier is released, the application writes every immutable request descriptor and the controller preloads, canonicalizes, hashes, and validates the complete contiguous sequence. `descriptorPreparedTimestamp` explicitly records this premeasurement preparation boundary; it is never interpreted as a live input-request timestamp. During a scheduled command the controller only looks up the prevalidated descriptor, records the live `dispatchStartedTimestamp`, requires the target application to remain foreground, and uses public `XCUIElement`/`XCUICoordinate` click, scroll, text, key, and mouse click-drag APIs. Drag commands convert the frozen trace duration from microseconds to the public `click(forDuration:thenDragTo:)` interval instead of substituting a zero-duration touch-style press. The typed dispatch result returns through an in-memory distributed notification. Controller receipts remain buffered until the application requests the post-measurement flush, at which point the controller persists canonical receipts and acknowledges completion. The select/replace command clicks `chat:append:16`, sends Home, sends Shift+Right exactly six times, and types `Oxide`; no other target, UTF-8 range, replacement, or nonadjacent event pair is admitted. The UI test owns an unconditional `defer` termination boundary so success, failure, timeout, or thrown validation errors cannot leave the comparison app foreground.

Controlled macOS sessions prepare the complete comparator scene and immutable input descriptors, then temporarily detach that prepared content behind an accessibility-empty placeholder while keeping the real application window visible and foreground. This gives `XCUIApplication.launch()` a quiescent start barrier even for large list and animation workloads while preserving the outer controller's exact-PID foreground requirement. The controller posts measured start only after launch returns and it preloads the exact input table; the application then restores the same prepared content immediately before starting the schedule. The detached interval is symmetric premeasurement setup and never replaces an input-driven frame or measured visual effect.

`MacOSTrustedInputWindow` observes the event delivered to the comparison application's real `NSWindow.sendEvent` path. The observer is armed from the prevalidated in-memory request identity and hash, records the required raw `NSEvent` family/type evidence, timestamp, location, window, foreground state, full trace-event range, and pre-command state generation, and finalizes only after the complete XCUI command returns. Select/replace requires ordered mouse-down and key-down evidence. The application observation is buffered in memory; after the measured scenarios end, the flush phase hashes the canonical controller receipt, constructs the bound application receipt, and persists it. It remains incomplete unless the exact raw families/types are present and the application state generation advanced during the command. No request-file read, JSON encode/decode, SHA-256 calculation, filesystem probe, or artifact write occurs in either side's scheduled dispatch path.

`BenchmarkCampaignExecutor` pauses schedule consumption while one trusted command is outstanding, retains already-due actions, and resumes only after both durable receipts validate. `InputReceived` uses the application-received timestamp, and neither it nor `VisualGeneration` is emitted before the raw event, foreground, hashes, and state transition validate. It calls `adapter.apply` only for declared application stimuli in measured macOS execution. Correctness remains an untimed direct-callback path. Completion and failure cancel the outstanding coordinator and clear deferred actions.

The AppKit adapter now uses a separate measured-interaction generation. It resets on measured prepare/reset and advances only inside native target/action, gesture, and text callbacks after the model mutation succeeds. Feed scrolling observes the real `NSClipView.boundsDidChangeNotification`, admits only a current wheel or mouse-drag event, writes the resulting bounds offset into the feed model, and then advances generation; programmatic prepare, reset, and trace-driven synchronization are suppressed. The navigation root's horizontal `NSPanGestureRecognizer` accepts a leftward drag from the visible list, presents progress from the real pointer position, and restores the list on mouse-up. Public XCUI has no pointer-cancel primitive, so the macOS override intentionally maps the frozen interactive-cancel sequence to one duration-preserving mouse click-drag-release command; release is the native endpoint's semantic cancellation boundary. No direct trace callback or hidden interaction overlay is permitted. The native `image.zoom` `NSSlider` likewise commits scale and generation through its existing target/action after actual mouse tracking. The frozen, naturally visible `chat:append:16` selection target is an editable `NSTextField` that retains the exact static Core Text raster, exposes the exact identifier to public XCUI, observes the field editor's exact `0:6` selection, accepts only the frozen final replacement, updates the model and visible row, restores the frozen thread position, and advances generation after each successful native mutation. Canonical launch keeps its independent generation.

The Oxide comparison Metal view routes real responder click, wheel, key, text, and drag events into Rust-owned scene state. Image zoom arms only inside `image.zoom`, maps the full track absolutely from 1x to 2x, and never snaps on release. Navigation drag exposes live progress and restores the list on mouse-up. Both AppKit and Oxide advance measured generation only after the real input mutates visible state and the render/accessibility update completes. The typed controller substitutions bind their full source ranges and require raw `mouseDragged` application evidence; unrelated pinch and cancellation shapes remain rejected before launch.

Focused coverage is documented in [macOS trusted-input control tests](tests/macos_trusted_input_control_tests.md).
