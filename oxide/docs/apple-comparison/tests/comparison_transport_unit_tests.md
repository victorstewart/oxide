# Apple comparison transport tests

`ComparisonHarnessUnitTests` verifies canonical durable JSON round trips, removal of temporary artifacts after rename, fail-closed generation mismatch behavior, and the native-side requirement for a canonical predecessor hash in per-app-container mode without consuming device time. A temporary, self-contained Apple PR root plan proves exact root-hash loading, canonical six-scenario order, and rejection of scenario-manifest byte drift without reading committed goldens. The suite also freezes the two-pack correctness expansion, pass-to-pack admission rules, exact controller chunk pack lists, semantic live-model/accessibility encoding and role-count rejection, all six scenarios' checkpoint contracts, trace-only startup scheduling through the 1-microsecond warm-resume checkpoint, effective `CTFontCopyVariation` values for every manifest role and axis, and inline-text variant validation for positive grids, unique roles/em sizes/cells, and exact grid-derived raster dimensions.

The UIKit reset source contract requires exactly six scene reset implementations plus the protocol and adapter entry points. It proves the adapter delegates to the existing scene and cannot call scene installation, teardown, or root-controller replacement during reset, while each mutable scene family exposes its seed-restoration operation. It also requires all 11 positive-radius UIKit layers to explicitly select circular corners; four deliberately square layers retain a zero radius and do not inherit OS-selected continuous/squircle coverage. The preview source contract freezes a live layer-tree render into an opaque standard-range 3x bitmap and rejects display-hierarchy capture, keeping presentation-compositor effects outside the exact static sRGB8 gate.

The fixed-recovery tests freeze overflow-safe 105% limit arithmetic and typed recovery-evidence round trips. The executor source contract proves checkpoint capture uses an autorelease pool, sentinel evidence performs no footprint wait or telemetry write, post-segment recovery orders quiescence before teardown, allocator pressure relief, and the deadline wait, correctness suppresses timing telemetry, and complete envelopes include the distinct recovery records. Telemetry coverage tests require one entry for every declared kind, distinguish common observed boundaries from external and unavailable evidence, and reject a presentation callback masquerading as a presentation sample. The suite also freezes Core Animation's native default display cadence on macOS and rejects the former unsatisfiable 80 Hz minimum. The macOS geometry case validates the frozen capture profile against live-sized landscape bounds and source-checks that the executor persists `geometry.actual.json` while the Oxide adapter derives it from `metalView.bounds`.

The device-only `ComparisonControllerUITests.testManifestCampaign` is the controller path for cross-target launch and control signaling. For the correctness chunk it launches both applications for both frozen packs even though the chunk has zero timed pair indices; synthetic execution indices exist only to give each app/pack side a distinct generation and artifact path. Each correctness receipt states that timing is not applicable. Per-app-container durability remains host-pullable and Darwin notifications remain generation-specific control wakeups rather than evidence.
