# Scenario schema tests

`crates/benchmark-spec/tests/scenario_tests.rs` freezes canonical JSON key order for the version-1 scenario fixture and verifies validation of schema versions, lowercase SHA-256 identities, content-addressed font/style/layout/trace inputs, elapsed-time ownership, unique metrics, measured phases, phase-bound parity checkpoints, optional canonical lowercase kebab-case recapture status, checkpoint-specific visible semantic roles, ordered integer trace timestamps, normalized coordinates, pointer identity, and mutation values. The committed Noto font pack is verified byte-for-byte with its licenses, pinned provenance, and exact `fvar`-ordered coordinates: Latin/Arabic `wght=400,wdth=100` and CJK `wght=400`. The asset fixture also freezes an inline-text grid with exact raster variants, graphemes, cells, em sizes, advances, baselines, widths, and heights. Dedicated rejection assertions cover missing, reordered, duplicate, non-printable, and out-of-range font axes plus duplicate graphemes, duplicate/out-of-grid cells, invalid variant geometry, and empty or noncanonical recapture status. A temporary fully materialized spec uses the real pinned Latin variable font bytes to prove exact SHA/axis validation and rejection of parent-directory traversal.

These tests are host-side contract checks. They do not establish visual parity or performance evidence for a runnable comparison scenario.
